Kata khusus, pengaturan, pilihan bahasa, emoji terbaru, dan riwayat papan klip disimpan lokal di perangkat Anda atau di kontainer app group. Anda dapat menghapus data lokal ini dengan membersihkan data lokal keyboard di pengaturan aplikasi, atau dengan menghapus instalasi aplikasi.

Minta penghapusan di sisi server

Untuk meminta penghapusan data sisi server — seperti log pemrosesan AI atau catatan dukungan — kirim email ke kami dan sertakan:

  • platform: iOS atau Android
  • perkiraan tanggal penggunaan
  • deskripsi masalah
  • jika tersedia, pengenal dukungan / perangkat anonim Anda dari pengaturan aplikasi

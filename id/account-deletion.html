TapFix AI Keyboard — Penghapusan akun dan data

App: TapFix AI Keyboard · Website: tapfixai.app · Support: support@tapfixai.app

Hapus akun Anda di dalam aplikasi

Anda dapat menghapus akun TapFix AI Keyboard di dalam aplikasi:

Buka TapFix AI Keyboard → Profil / Pengaturan akun → Hapus akun.

Minta penghapusan via email

Jika Anda tidak lagi memiliki akses ke aplikasi, Anda dapat meminta penghapusan akun via email:

support@tapfixai.app

Kirim permintaan dari alamat email yang terhubung dengan akun TapFix Anda dan gunakan subjek:

Account deletion request

Data apa yang dihapus

Saat akun dihapus, kami menghapus akun, catatan autentikasi, data profil, pengaturan cloud, preferensi tersimpan, dan data TapFix lain yang terkait dengan akun.

Berapa lama

Permintaan penghapusan akun diproses dalam 30 hari.

Data apa yang mungkin disimpan

Beberapa data mungkin disimpan hanya jika diperlukan untuk alasan keamanan, pencegahan penipuan, hukum, pajak, pembayaran, atau kepatuhan.

Hapus data tertentu tanpa menghapus akun

Untuk meminta penghapusan data tertentu tanpa menghapus akun, kirim email ke support@tapfixai.app dan gunakan subjek:

Data deletion request

Jelaskan data apa yang ingin dihapus.

Pengguna iOS

Di iOS, TapFix AI Keyboard tidak memerlukan akun. Data lokal dapat dihapus dengan membersihkan data lokal keyboard di pengaturan aplikasi atau menghapus instalasinya. Untuk meminta penghapusan data sisi server seperti log pemrosesan AI atau catatan dukungan, lihat halaman Hapus Data Saya atau kirim email ke support@tapfixai.app.

Lihat juga Kebijakan Privasi kami.

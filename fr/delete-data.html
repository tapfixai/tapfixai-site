Supprimer les données locales sur votre appareil

Les mots personnalisés, les réglages, les choix de langue, les emojis récents et l'historique du presse-papiers sont stockés localement sur votre appareil ou dans le conteneur du groupe d'apps. Vous pouvez supprimer ces données locales en effaçant les données locales du clavier dans les réglages de l'app, ou en désinstallant l'app.

Demander la suppression côté serveur

Pour demander la suppression des données côté serveur — comme les journaux de traitement IA ou les enregistrements d'assistance — écrivez-nous et incluez :

  • plateforme : iOS ou Android
  • date d'utilisation approximative
  • description du problème
  • si disponible, votre identifiant anonyme d'assistance / d'appareil issu des réglages de l'app

Délai de traitement

Nous traiterons les demandes de suppression conformément aux lois sur la confidentialité applicables, sous 30 jours.
